# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to
[loongforge@baidu.com](mailto:loongforge@baidu.com).
Include the following details.

- The affected commit, release, or container tag.
- The affected component and environment.
- A description of the issue and its potential impact.
- Any disclosure timeline or coordination constraints.

Keep vulnerability details out of public issues, pull requests, discussions,
and chat channels until disclosure is coordinated. The project team uses the
report to assess affected versions and coordinate fixes or mitigations.
