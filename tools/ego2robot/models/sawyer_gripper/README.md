# Sawyer Electric Gripper

This MJCF is a MuJoCo conversion of the Rethink Robotics Intera Sawyer
Electric Gripper description from `intera_common`.

Included visual assets:

- `connector_plate.stl`
- `electric_gripper_base.stl`
- `standard_narrow.stl`
- `basic_soft_tip.stl`

The source package and license are kept alongside this model. The MJCF keeps
the official connector-plate layout, standard-narrow finger geometry, finger
travel, and TCP placement while removing ROS/Xacro-only elements.
